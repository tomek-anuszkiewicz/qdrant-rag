# Repository language

Write new or substantially revised documentation, agent files, identifiers, comments, and help text in English. Answer the user in their language. Preserve historical text outside the task's scope; translate affected surrounding text when leaving a mixed-language paragraph would make it hard to read.

The preflight checks Polish diacritics in staged added lines. It is a narrow mechanical signal, not proof that all text is English. Review the diff for unaccented Polish and awkward literal translations.
